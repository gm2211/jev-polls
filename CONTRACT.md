# Implementation contract

`src/types.ts` is the shared contract. Input JSON uses strict versioned schemas.

- `src/schema.ts`: parseCohort(input), parsePipeline(input), loadProject(pipelinePath) -> Promise<{pipeline, cohorts}>; validate graph including declared ancestor conditions and duplicate ids; exported schemas and JSON schemas.
- `src/engine.ts`: runPipeline(pipeline, cohorts, options) -> Promise<RunRecord>; topological stage execution, parallel ready stages, a global bounded request limiter, stage conditions, per-persona questions batched, reusable exact-response cache, deterministic sampling without replacement, cohort segment weights preserved; repeats averaged without manufacturing sample size. Poll state includes persona, shared context, stage context, and explicit named input projections; absent bindings preserve legacy direct upstream summaries. Input refs require direct dependencies, valid outputs, and compatible projections; missing optional outputs become null. Aggregate inputs must be compatible types/options and declared dependencies. Decision preserves source summary and declares a selection, never creates fake certainty. Failed dependencies skip descendants; return failed run with partial results, never silently drop failed voters. Validate and reject malformed provider answers before caching/aggregation. Provider results and cached responses are validated before aggregation.
- `src/analysis.ts`: summarizeVotes(questions, votes); compareRuns(runs, stageId, questionId); simulateVotes(run, stageId, questionId, draws, seed). Weighted probability means, segment and repetition breakdowns. Simulation intervals labeled conditional on model outputs, never real-world confidence.
- `src/provider.ts` + `src/auth.ts`: createProvider(name, config?) returns Provider; config may contain apiKey in memory, never log it. Mock must be deterministic and prominently identified, no inference claims. Live provider uses current official SDK and validates responses, retries transient errors, bounds timeouts, sanitized failures. `readApiKey`, `authStatus`, `setApiKey` use environment or macOS Keychain. Verify fake-secret handling before using real credentials. No secrets in args/files/output.
- `src/report.ts`: renderReport(run: RunRecord): string; standalone HTML with inline CSS/JS, no network dependencies, responsive keyboard-accessible UI, pipeline graph/stage navigation, segment filters, distributions, respondent drilldown, source provenance, assumptions, repeat breakdown, distinct simulated labels, JSON export. Escape all untrusted data, prevent script closing/XSS. No framework needed.
- `src/workspace-store.ts` + `src/workspace-types.ts`: editable draft contracts separate from runnable cohort/pipeline validation, atomic revision-controlled persistence, cohort ID resolution and request planning.
- `src/workspace.ts` + `src/workspace-ui.ts`: loopback browser workspace with cohort forms, visual pipeline editing, explicit review and run, account verification separated from study execution, and persistent report history. Host, Origin and CSRF checks protect mutations; revision-bound one-use review tokens gate execution.
- `src/local-agent.ts`: bounded asynchronous local Codex/Claude CLI drafting, existing login, prompts via stdin, isolated temporary work, structured proposals validated before explicit revision-safe application, cancellation and cleanup. No automatic workspace writes or TypeSafe inference; never expose CLI diagnostics or secrets.
- `src/mcp.ts` + `src/agent-config.ts`: official MCP stdio adapter for existing agents, credential-free client configuration, revision-safe cohort/pipeline upserts, and explicit review/run tools sharing the running workspace server. Never log or return account keys. Preserve dirty browser drafts when agent edits arrive.
- `src/cli.ts`, examples, README, agent guide: commands init, schema, validate, plan, run, report, compare, simulate, cohort list/import/sample, auth status/set/check, workspace and connect. JSON stdout and progress stderr. Local files only; report doesn't call APIs. Native Node 22+, TypeScript, npm.

Use explicit `.js` extensions for local imports. Tests exercise each module and the CLI as an integrated workflow. Run `npm run verify` before committing.
